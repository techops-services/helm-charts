This stack is meant to be deployed atomically. Roll the whole thing together
and roll all of it back if any component fails its readiness check:

  helm upgrade --install {{ .Release.Name }} charts/keeperhub-stack \
    -f keeperhub/deploy/keeperhub/<env>/values.yaml \
    --namespace {{ .Release.Namespace }} \
    --atomic --wait --timeout 15m

Check rollout:
  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ .Release.Name }}-app
